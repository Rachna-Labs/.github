# .github (rachna-labs)

Org-wide GitHub files. Local folder name: `org-github`.

- `.github/workflows/kmp-check.yml` - the reusable CI every KMP repo calls. Change it here once; every repo picks it up.
- `profile/README.md` - the public org page. Public, so only verified facts.
- `pull_request_template.md`, `ISSUE_TEMPLATE/`, `SECURITY.md` - defaults for every repo that has none.

This repo is public. Never put secrets, internal plans or unreleased product details here.
